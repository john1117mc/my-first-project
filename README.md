# my-first-project

我的第一个 GitHub 仓库，用来练习 Git 与 GitHub 的基本工作流。

## 这个仓库在练什么

- 用 `git commit` 把每次修改记录成历史
- 用 `git push` 把本地代码同步到 GitHub
- 用分支 + Pull Request 和别人协作

## 日常三步

```powershell
git add .                    # 把改动放进待提交区
git commit -m "改了什么"     # 存一个版本快照
git push                     # 推到 GitHub
```

## 常用命令速查

| 命令 | 作用 |
| --- | --- |
| `git status` | 看当前改了什么 |
| `git log --oneline` | 看提交历史 |
| `git diff` | 看具体改了哪几行 |
| `git pull` | 拉取远程的新改动 |
| `git switch -c 分支名` | 新建并切换分支 |
